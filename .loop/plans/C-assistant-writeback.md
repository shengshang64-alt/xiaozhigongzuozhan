# C 类方案 · 小智助手技能产出「一键采用/写回」（⑤）

> 提出轮次：R60（2026-09-25）· 状态：**等用户确认** · 预估 1–2 轮

## 做什么

小智助手技能（跟进邮件/深度竞品分析/行业周报等）的产出卡新增「采用」动作，按技能类型给落点：

| 技能类型 | 采用动作 |
|---|---|
| 跟进邮件 / 跟进话术 | 复制全文 + 可选「存为客户跟进记录」：弹客户选择器 → 写入现有 follow_records 集合（经既有自定义接口，**零 schema 变更**） |
| 深度竞品分析 | 复制报告 + 「去竞品档案」跳转竞品详情（内容已在剪贴板，粘贴即用；不自动写档案字段——写回一律走既有「采纳」流程防脏数据） |
| 行业周报 | 复制 + 下载 .docx（复用现有导出工具函数） |

## 为什么

R58 审计断点②：技能产出只能逐条手抄，无法回写任何下游；跟进邮件生成完还要切到客户管理手工录跟进。

## 动哪些文件

- `src/components/assistant/ChatStream.tsx`：技能产出卡加「采用」下拉（按技能类型渲染动作）
- `src/pages/Assistant/useAssistant.ts`：采用动作（识别技能类型 → 路由）
- 客户跟进写入：复用客户管理现有跟进记录接口（实现前先 spike 确认接口签名，不匹配则降级为"复制+跳客户管理"）

## 数据影响

零 schema 变更；仅新增 follow_records 业务记录（用户显式点击才写，带确认）。

## 边界

不做自动写方案/标书正文（跨模块注入风险大，先观察跟进记录写回的使用率再说）。

**确认回复**：「同意」开工；或指定只要其中某类技能的采用动作。
