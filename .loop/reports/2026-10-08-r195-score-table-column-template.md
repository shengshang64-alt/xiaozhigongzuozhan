## 2. 方案：表头锚定的列模板（五重护栏）
不猜列、不猜行长度，改由**表头授权**后按列取值：

1. **标签列定位**：表头须同时出现项目标签列（评标项目/评分项目/评审因素/评分因素/评标方法/评分标准/评分项）
   与分值标签列（以「分值/得分/权重」结尾或恰为分值类词），且分值列必须位于项目列之后 → 返回分值列下标。
2. **列数严格一致**：其后仅在列数完全相同的行上按列取值；任一行列数不符 → 模板立即失效（限定作用域，
   防止无限续存吞掉后面的同形表）。
3. **分值数值域**：分值单元须为纯数字 / 「N分」 / 区间（取上界），且 0 < v ≤ 100，否则不可信。
4. **描述格评分语汇锚**：分值列右侧描述格须含 得N分/不得分/满分/扣/评分/评标/评议/评价/响应/满足/证书/
   业绩/方案/能力 才采纳——同形状的采购清单、数据集目录、付款方式表因此不会被误读成分值。
5. **无表头不提取**：没有表头授权的裸多列行一律不按列取分值（守住目录页码「第五章 政府采购合同 | 39」）。

项名规则：分值列前一格若是纯编号（`1-1` / `T1、` / `①` / `2.1`）→ 项名取描述格主题并**回挂编号**
（`技术功能响应情况（1-1）`），保证逐条同主题评分项不互相覆盖、且仍可被 `nameSimilar` 双向包含匹配到 AI 报告项；
否则项名取该格，**先剥编号前缀再切标点**（`T1、技术服务响应程度` → `技术服务响应程度`），
名称格**不按顿号切**（`节能、环境标志产品` 是一个评审因素）。

命中即 `continue` 消费该行，不再进单行启发式（防重复入项）；未命中则原样回落既有归一与单行启发式（只增不减）。
