# R65 · 2026-10-28 11:55

## 本轮做了什么（一句话）

情报卡片下面那段「摘要」里，有一半以上显示的是**别人文章的标题**——本轮把它挡住了：能确认是本文正文的留下，确认不了的改成一句如实的提示，不再冒充摘要。

---

## 为什么做这件事

先说现象。今天上午打开首页，随便挑一条情报：

> **标题**：浙江发布会："安诊儿"已接入2000+医疗机构，将建强中试基地，全面推广医疗大模型
> **下面那行字**：甘肃省进一步健全城市社区卫生服务体系提升服务能力的十项措施 2026-10-27 2026-10-26 江苏省印发《推进江苏省"人工智能+医疗健康"发展实施方案》 2026-10-23

标题说的是浙江，正文讲的是甘肃和江苏。这不是排版问题，是**这条情报的「内容片段」字段里，装的就是源网站列表页上其他几条新闻的标题**。

抓取程序进源站时，进的是「栏目列表页」而不是文章正文页，于是把列表页上「标题 + 日期 + 标题 + 日期」整片抄了回来。另一批是「更多... 更多... 更多... 日期 正文」，前面那几个「更多...」是网页上的按钮文字。

我在真实库里数了一遍（728 条情报，672 条有这个字段）：

- 含「更多…」按钮文字的：**166 条**
- 含两个以上日期的（基本就是列表）：**345 条**
- 两类都有：143 条
- **合计 368 条（54.8%）在修之前，用户读到的是别的东西**

而这些字被当成「摘要」显示了**两个地方**：首页的「情报摘要」卡片，和情报中心右侧详情面板的「内容片段」。详情面板那处更直接——它是原样打印字段内容，一个字都没洗。

> 为什么上一轮（R64）没修好？R64 修的是同一字段的另一种脏法（页面 JSON 元数据），
> 但它的判断规则是「一行里有花括号就丢」。列表残片里没有一个花括号，全是正常中文，所以一条都拦不住。

## 你怎么自己验证（照着点鼠标就行）

前提：浏览器打开 `http://127.0.0.1:8000/`（前端），后端 :7000 要在跑。

**第一步：看首页那排情报卡**

1. 打开首页（`http://127.0.0.1:8000/`），往下滚到「**情报摘要**」这一块（标题下面一行小字是「来自情报中心的最新政策与竞品中标动态」）。
2. 逐张看卡片第二行（灰色那段字）。现在应该是三种之一：
   - 一段像样的中文新闻正文（比如「2026"数据要素×"大赛名单公示：… 10月24日，国家数据局公示…」）；
   - 或者一句「**暂无摘要，进入情报中心用 AI 摘要打标**」。
3. **不该再出现**：一长串别的文章标题 + 一串日期；也不该出现「更多... 更多...」。

> 修之前这里长这样（对照用）：
> 卡片1 = 「甘肃省…十项措施 2026-10-27 2026-10-26 江苏省印发《…》 2026-10-23」
> 卡片3 = 「行情 数据 更多... 更多... 2026-10-27 讷河市…」
> 卡片4 = 「ight 更多... 医疗健康领域43个项目获奖！…」

**第二步：看情报中心的详情面板**

1. 点左侧导航「**情报中心**」。
2. 在右上角搜索框里输入「**浙江发布会**」，回车，点开那条卡片。
3. 看右侧详情面板的「**内容片段**」——应该是一句：
   「该条抓取自栏目列表页，片段是其他条目的标题列表，与本文无关，已隐藏；请点「查看原文」阅读正文。」
4. 再搜「**数据要素**」，点开「多地启动个人医保云试点申报工作…」那条——它的「内容片段」应该是一段正常正文（不是提示语）。

在项目根目录执行：

## 遗留与新发现

1. **根子还在抓取端**：`pb_hooks/intel_center.pb.js` 仍会把列表页骨架写进这个字段，新抓的条目会继续产生脏片段。本轮只在「显示」这一层挡住，没有改抓取。
   → 要根治必须改这个钩子文件，并且**改完需要你重启 :7000 才生效**（项目规则禁止我自己结束进程）。
2. **作战室那处没修**：`src/components/bid-workspace/BidWarRoom.tsx` 里「作战室情报」也用同一个字段兜底，同样会把列表残片显示出来。那个目录此刻有别人未提交的改动，我没碰。
3. **情报中心列表卡片**只显示「摘要」，没有片段兜底——所以同一批条目在首页有内容、在列表卡片是空白。这是「要不要也兜底」的产品判断，不是 bug。
4. **另一处同字段**（摘要 `summary`）目前没有「更多…」，66 条里 0 条命中，属预防性缺口，单独一轮再做。
5. **顺带核实**：`docs/测试报告` 里的 BUG-002「竞品分析 Tab 无法切换」**已经不存在了**（今天实机点「厂商档案」能正常切换），已从待办里关掉。
