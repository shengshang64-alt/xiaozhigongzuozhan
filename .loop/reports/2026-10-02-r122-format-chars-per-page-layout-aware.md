# R122 每页折算系数纳入纸张/页边距可用版面（E1 收尾）

日期：2026-10-02 · 轮次：122 · 优先级：P2

## 背景
本会话前序切片 E1 已把标书"页数↔字数"折算从硬编码 500 改为按正文格式动态计算，但 `formatCharsPerPage`
仅计入了**字号 + 行距**，未纳入**纸张（A4/A3/16K）与页边距**对"一页实际能放多少字"的影响（E1 自测留档第六节已登记为遗留项）。

## 改动（仅 bidTypes.ts + 新增测试）
- 新增 `PAPER_DIM_CM`（A4/A3/16K 页宽×页高 cm）与 `usableAreaFactor(settings)`：
  可用版面 = (页宽 − 左右边距) × (页高 − 上下边距)，取相对 A4 默认边距的比值。
- `formatCharsPerPage` 升级为：
  `cpp = 500 × 可用版面面积比 × (14/pt)² × (1.5/行距倍率)`，限幅由 [200,1400] 放宽到 [150,2600]（容纳 A3）。
- **零回归保证**：默认格式（A4 / 默认边距 2.54·3.18 / 四号 / 1.5 倍）三因子恒 = 1，结果精确等于 500，
  所有未改字号/纸张/边距的存量项目行为字节级不变。

## 新增单测（formatCharsPerPage.test.ts，7 用例）
1. 默认 / undefined / null → 500
2. 字号：小四 681、三号 383、五号 889
3. 行距：单倍 750、2倍 375、固定值21磅 650
4. 纸张/边距单调性：A3 > A4 > 16K；宽边距 < 默认
5. 极端组合落 [150,2600] 限幅
6. `estimatePagesFromChars` 按 charsPerPage 折算（1000/500=2、1000/1000=1）
7. `chapterWordBudgets` 总量随系数线性放大（10 页×系数）
