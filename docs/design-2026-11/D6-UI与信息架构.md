## 3. 错误 / 空态 / 长任务原则（继承 redesign，写成验收口径）

1. **空态即行动邀请**：空列表给「新建/导入/去配置」之一，不给死白屏。  
2. **错误可理解**：写清「谁失败、用户下一步」；禁止甩未配置模型名；禁止把网关超时说成「模型服务挂了」除非确证。  
3. **长任务**：解析/生成/聊天 > 数十秒必须有进行中态；失败要留在原场景可重试；能取消则取消。  
4. **AI 是副驾**：费用先确认（现有成本弹窗保留）；导出仍过交卷闸门。  
5. **数字诚实**：同一概念（废标条数、满分、覆盖率）同一屏前后一致；不一致先修文案或分母，再谈美化。  
6. **令牌克制**：继续医疗青主色与冷灰；不准页面硬编码乱色（SDD §7 硬约束仍有效）。
