## 1. 产品一句话

小智工作站是**医疗信息化售前的本地/局域网编制台**：把情报与客户线索，变成方案、标书、PPT/报价，并能沉淀知识复用——AI 是副驾，**人工确认是护城河**。

## 4. 三条主链路（继承 PRD，本轮聚焦断点）

### 4.1 项目获取 → 投标交付

`情报/客户 → 立项 → 标书解析 → 大纲 → 正文 → 查重/废标 → 评标 → 交卷导出`

**断点（本轮必盯）**：解析超时误导、大纲草稿内存态、后 4 步使用率极低（docs/23）、导出闸门与目录对照小错。

### 4.2 知识沉淀 → 复用

`入库 → 检索/问答 → 素材注入正文/方案`

**断点**：问得到不稳定；注入曾默认关/为 0；缺轻量混合检索（D1：必须补，工程走两阶段，不整站 RAG 平台）。

### 4.3 情报 → 商机

`源抓取 → 去重打分 → 周报 → 一键转商机`

**断点**：前端驻留触发；失败源无运维闭环。目标改服务端跑（D3/D5），产品形态借「逐源历史」（D1）。

## 5. 与 Harness / xz-mcp 的产品分工

| 事 | 工作站 | Harness |
|---|---|---|
| 写标书/方案/PPT 主流程 | **主场** | 可旁路询问，不替代七步 UI |
| 查客户/方案/报价等约定数据 | UI + API | MCP 工具只读/确认码写入 |
| 长期记忆 / 定时推送 | 通知表可收 | 后续期；微信转发器根因另查 |
| 改业务代码 | Open Design 单通道 + Bot 验 | **不**用 Harness 改仓 |

原则：用户感知可以是「两个助手」，数据真相只有工作站库一份。
