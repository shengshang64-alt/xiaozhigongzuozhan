# 第二批任务（高价值，先做这三个）

## 任务 A：资质台账（`src/pages/QualCerts/`）

### 为什么改
这是防废标的关键页面，但：① 五张统计卡里**最危险的「未登记有效期 25 张」视觉上和普通数字一样**；② 预警条只能跳到台账首页，不能定位到具体那一行证书；③ 编辑/删除图标只有 16px，点不准；④ 34 条数据无批量操作。

### 改成什么样
1. **统计卡按危险度着色重排**：已过期(红)→30天内到期(橙)→未登记有效期(黄)→90天内(灰)→总数(灰)。「未登记有效期」卡片文案改为「⚠ 25 张未登记有效期」，点击后表格自动过滤出这 25 条
2. **预警条逐条可定位**：每条预警加「定位」按钮，点击后表格 `scrollIntoView` 到该行并加 `animate-pulse` 高亮 2 秒
3. **操作列改为 ⋯ 菜单**：编辑/查看扫描件/续期登记/删除（删除走二次确认）
4. **表格加复选框列**：支持全选，选中后出现浮动操作条「批量登记有效期 / 批量导出 / 取消选择」
5. 「批量登记有效期」弹窗：一个日期选择器，应用到所有选中行

### 验收标准
- [ ] 5 张统计卡颜色与危险度一一对应，未登记卡点击可过滤
- [ ] 预警条每条可定位到表格行并有高亮动画
- [ ] 删除证书弹二次确认，确认后 toast 提示
- [ ] 批量选中 3 条以上时浮动条出现，批量登记生效
- [ ] 门禁三条全过

## 任务 B：客户管理（`src/pages/CustomerManagement/`）

### 为什么改
① 未选客户时**右半屏（约 50% 面积）只有一句"请从左侧选择"**；② 客户卡上的「缺 N 项」角标**点击没反应**，用户不知道缺什么、去哪补；③ 顶部「未配置任何可用模型」警告永久占位；④「批量补全/全量补全」两按钮无区别说明，用户不敢点。

### 改成什么样
1. **右栏默认态**：未选客户时显示「客户健康度总览」面板——30 天未跟进客户数、档案完整度分布条、最近新增客户 Top5（数据从现有 hooks 取，没有就先放静态占位并留 TODO 注释）
2. **「缺 N 项」角标可点击**：弹出 Popover 列出具体缺失字段（如"信息化评级 / 联系人 / 系统厂家"），每项带「去补全」链接跳到编辑弹窗对应字段
3. **模型警告降级**：从常驻横幅改为页面右上角一个小黄点图标，hover 显示说明，点击跳模型配置
4. **批量补全按钮加 hover 说明**（Tooltip：仅补全勾选项/全量补全=扫描所有客户所有缺失字段）+ 点击后弹确认窗显示「将影响 N 家客户，预计 X 分钟」

### 验收标准
- [ ] 未选客户时右栏显示健康度面板而非空白
- [ ] 点击「缺 N 项」弹出缺失清单且每项可跳转
- [ ] 顶部不再有常驻模型警告横幅
- [ ] 批量补全有预览确认
- [ ] 门禁三条全过

## 任务 C：情报中心（`src/pages/IntelCenter/`）

### 为什么改
这是全站信息密度最失控的页面（整页 3600px）：① 处理 20 条待确认情报要上下滚动 3 屏；② 指标卡「29/40」「980」「40」「0」语义混乱；③ 大段蓝色数据源说明永久占首屏；④ 左侧筛选栏 + 中部筛选行两级并存；⑤ 每条情报 5 个操作平铺，最高频的「确认」和最低频的「编辑」视觉权重一样。

### 改成什么样
1. **双模式切换**（页面顶部放视图开关）：
   - 「待办模式」（默认）：只显示待确认情报，卡片放大，每条右下角一个实心「确认」主按钮
   - 「浏览模式」：全部情报，紧凑行式列表（单行高约 64px，标题截断）
2. **指标卡语义化**：改为「本周待确认 29 条 ▼较上周」「本月已抓取 980 条」「本月新增 40 条」「已转报 0 条」，每张卡点击直达对应过滤视图
3. **数据源说明**收进「ⓘ」图标的 Popover
4. **筛选收敛**：只留一行（来源类型片 + 状态片 + 搜索框），高级筛选（标签/时间/网站）收进「高级筛选 ▾」抽屉
5. **操作分层**：主操作「确认」实心按钮；「AI 摘要 / 标重点 / 编辑 / 原文」收进 ⋯ 菜单
6. 确认操作后该行以动画从待办列表滑出（用现有 tailwindcss-animate）

### 验收标准
- [ ] 默认进「待办模式」，待确认情报一屏可见 ≥5 条
- [ ] 确认按钮点击后该行消失并有滑出动画 + toast
- [ ] 指标卡文案全部语义化且可点击过滤
- [ ] 首屏不出现数据源说明长文字
- [ ] 门禁三条全过
