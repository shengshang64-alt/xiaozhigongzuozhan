## 0. 结论速览

### 总体验收结论

这是一套 **AI 主链路真实可用、日常走查零阻断错误、但安全与工程护栏存在系统性欠账** 的工作台。它不是"演示壳"——用 845 页真实招标文件跑了一次完整 AI 解析，7/7 分区成功、字段级抽查 10/10 正确、且在找不到分值表时**如实标注缺项而非编造**，反幻觉护栏在真实样本上站住了。同时，它也**不具备直接对外演示或多人联网使用的条件**：身份头自证、IDOR、遗留路由明文 dump API Key、零测试网、提示词未抽离、双账本断裂等问题，在"本机自用"假设下可控，一旦暴露到局域网/公网或交给 LLM 自主迭代，就是高危。

### 6.2 招标参数生成与技术响应

- **防幻觉**：边界表 + 历史负例自检已落地（实测反幻觉好）；继续保持。
- **逐条对应 / 星号废标锁定**：大纲/正文/废标检查三处锁定已落地。
- **负/正偏离**：偏离表当前恒走"保守"口径，未按 strict/moderate/full 模式区分（F-BID-02）——这是三模式设计的核心价值，必须补。

- **知识库引用**：当前只要求"注明来源文档"字符串，无结构化句尾出处（F-BID-10）。

### 6.3 方案生成三模式限制
