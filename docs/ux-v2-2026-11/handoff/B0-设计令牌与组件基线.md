## 三、任务 1：追加设计令牌（`src/index.css`）

**做法**：在文件末尾**追加**一个新的 `@layer components` 块，不改现有 `:root` 里任何已有变量的值。

### 3.1 需要追加的语义色（如果项目里还没有）

先 `grep` 确认，已有就跳过：

```powershell
Select-String -Path src\index.css -Pattern "--warning:|--success:|--info:"
```

设计规范要求 5 档语义色（见 `docs/ux-v2-2026-11/02-设计规范与组件约定.md` §2.1）：

| 语义 | 用途 | 绑定动作 |
|---|---|---|
| `destructive`（已有） | 废标 / 已过期 / 不可导出 | 必须处理，不处理会失败 |
| `warning`（已有） | 30 天内到期 / 超 30 天未跟进 | 本周内处理 |
| —— 待补 `amber` | 未登记 / 待确认 / 低于建议值 | 需要人判断 |
| —— 待补 `success` | 已确认 / 已通过 / 中标 | 无需动作 |
| —— 待补 `info` | 编制中 / 已开始 / 在流转 | 观察进度 |

**如果项目已有 `--warning`，就只补缺少的那几档。** 补法（HSL 三通道，与现有写法一致）：

```css
:root {
  /* 语义色补全（v2）：只补缺的，不改已有 */
  --success: 165 70% 31%;        /* #17876B 完成/通过/中标 */
  --info: 212 59% 44%;           /* #2E6FB0 进行中 */
  --amber: 42 80% 38%;           /* #B08313 未登记/需判断 */
}
```

⚠️ **动 `:root` 时必须只新增行，不许改已有行的值。** 改现有色值会影响全站 17 个页面，属于越界。

### 3.2 需要追加的组件类（`@layer components`）

严格照 `docs/ux-v2-2026-11/prototype/assets/design.css` 里对应的类翻译成 `@apply`。
**只追加这几个**（其余在原型的 CSS 里有，但项目里用 Tailwind 直接组合就行，不必都做成类）：

```css
@layer components {
  /* 语义徽标扩到 8 档（现有 4 档：success/warning/danger/neutral，补 4 档） */
  .badge-info    { @apply rounded-full border-transparent bg-info/10 px-2.5 py-0.5 text-xs font-medium text-info; }
  .badge-amber   { @apply rounded-full border-transparent bg-amber/10 px-2.5 py-0.5 text-xs font-medium text-amber; }
  .badge-purple  { @apply rounded-full border-transparent px-2.5 py-0.5 text-xs font-medium; }
  .badge-primary { @apply rounded-full border-transparent bg-primary/10 px-2.5 py-0.5 text-xs font-medium text-primary; }

  /* 数据条（替代「3 个数字占 3 张大卡」，原型里 .databar） */
  .databar { @apply flex flex-wrap items-center rounded-lg border border-border bg-card py-2 shadow-sm; }
  .databar-item { @apply flex items-center gap-2 border-r border-border/60 px-4 text-xs text-muted-foreground last:border-r-0; }
  .databar-item b { @apply font-mono text-[15px] font-semibold text-foreground; }

  /* 横向条形图（原型 .cbar；注意 fill 必须 display:block 否则宽度不生效） */
  .cbar { @apply grid items-center gap-2.5 text-xs; grid-template-columns: minmax(96px,auto) minmax(0,1fr) 62px; }
  .cbar-track { @apply flex h-4 items-stretch overflow-hidden rounded-sm bg-secondary; }
  .cbar-fill { @apply block h-full min-h-4 rounded-sm bg-gradient-to-r from-primary/70 to-primary; }
}
```

**注意 `@apply` 里不能用 `grid-template-columns`**，所以上面 `.cbar` 那条要把 `grid-template-columns` 单独写成普通 CSS 属性（如上行所示混写是可以的）。

## 四、任务 2：新增 `StatCard` 组件

**文件**：`src/components/ui/StatCard.tsx`（约 60 行）

**原型对照**：`design.css` 的 `.stat` / `.stat.is-red` 等，原型页面里 `home/index.html` 有 4 个实例。

**API**：

```tsx
type StatTone = "default" | "red" | "orange" | "amber" | "green" | "blue" | "primary"

type StatCardProps = {
  label: string
  value: ReactNode            // 数字或数字+单位
  unit?: string               // 单位，如「项」「条」「天后」
  foot?: ReactNode            // 副文案，如「已过期 1 · 30 天内 3」
  tone?: StatTone             // 左侧 3px 语义色边
  icon?: ReactNode            // 标签前图标（15px）
  onClick?: () => void        // 可点时整卡可点 + hover 抬升
  className?: string
}
```

**视觉要求**（逐条对照原型）：

| 项 | 值 |
|---|---|
| 卡片 | `rounded-lg border border-border bg-card p-3 shadow-sm` |
| 语义色边 | `border-l-[3px]` + 对应色，**只有 `tone !== "default"` 时才有** |
| 标签 | `text-xs text-muted-foreground`，图标 13px |
| 数值 | `mt-1 font-mono text-[23px] font-semibold leading-tight tracking-tight` |
| 单位 | `ml-1 text-xs font-medium text-muted-foreground`（**不能是 mono**） |
| 副文案 | `mt-0.5 text-[11px] text-muted-foreground` |
| tone 对应数值色 | red→`text-destructive`、orange→`text-warning`、green→`text-success`、blue→`text-info`、amber→`text-amber`、primary→`text-primary` |

**语义色边的映射**（`tone` → class）：

```ts
const EDGE: Record<StatTone, string> = {
  default: "",
  red: "border-l-destructive",
  orange: "border-l-warning",
  amber: "border-l-amber",
  green: "border-l-success",
  blue: "border-l-info",
  primary: "border-l-primary",
}
```

## 五、任务 3：新增 `DataBar` 组件

**文件**：`src/components/ui/DataBar.tsx`（约 45 行）

**为什么要它**：原型里大量用「一行数据条」替代「3 张统计卡」（省 200px 高度）。
见诊断书 §3.4：方案工作室 3 张等宽大卡装 3 个小数字，纯浪费。

**API**：

```tsx
type DataBarItem = {
  label: string
  value: ReactNode
  tone?: "default" | "red" | "orange" | "green" | "blue" | "amber" | "primary"
}
type DataBarProps = {
  items: DataBarItem[]
  /** 右侧附加内容（如「去跟进队列 →」） */
  trailing?: ReactNode
  className?: string
}
```

**视觉**：`.databar` + `.databar-item`，项之间 `border-r`，`tone` 只影响 `<b>` 的颜色。

**决策规则（写进组件注释）**：
- 指标 **≥4 个且每个都有独立行动含义** → 用 `StatCard` 网格
- 指标 **≤3 个，或只是"计数汇总"** → 用 `DataBar`

## 六、任务 4：新增 `Drawer` 组件

**文件**：`src/components/ui/Drawer.tsx`（约 90 行）

**背景**：原型里大量用「右侧抽屉」承载详情（情报详情、检查报告、模型测试）。
项目当前**没有** Drawer，只有 `ui/dialog.tsx`（Radix Dialog 的居中弹窗）。

**做法**：基于 `@radix-ui/react-dialog`，写一个 `side="right"` 变体。

**API**：

```tsx
type DrawerProps = {
  open: boolean
  onOpenChange: (open: boolean) => void
  title: ReactNode
  description?: ReactNode
  /** 头部右侧额外动作 */
  headerExtra?: ReactNode
  children: ReactNode
  /** 底部固定操作区 */
  footer?: ReactNode
  /** 宽度，默认 560，最大不超过 720 */
  width?: number
}
```

**视觉要求**（对照 `design.css` 的 `.drawer` / `.drawer-mask`）：

| 项 | 值 |
|---|---|
| 遮罩 | `fixed inset-0 z-[80] bg-[#0B2430]/36` |
| 面板 | `fixed right-0 top-0 bottom-0 z-[81] flex flex-col bg-card shadow-2xl` |
| 面板宽度 | `style={{ width: Math.min(width, 720) }}`，移动端 `max-w-full` |
| 头部 | `flex items-center gap-2.5 border-b border-border px-4 py-3.5`，标题 `text-[14.5px] font-semibold` |
| 内容 | `flex-1 overflow-auto px-4 py-3.5` |
| 底部 | `flex justify-end gap-2 border-t border-border bg-muted/30 px-4 py-2.5` |

**必须处理的两件事**（项目已有前车之鉴）：

1. **`data-dialog-exit-guard`**：`src/index.css` 里有针对 Radix 退出态的守卫（`[data-dialog-exit-guard][data-state="closed"] { pointer-events:none; opacity:0 }`）。你的 Drawer 如果是 Radix Dialog 派生，**必须带上这个属性**，否则关闭动画期间会挡住全页点击（项目历史上实测 6s+）。
2. **无障碍**：`aria-labelledby` 指向标题，`aria-describedby` 指向 description（没有 description 就不写）。

## 十、异常处理

| 情况 | 怎么办 |
|---|---|
| 项目里已有同名的 `StatCard` / `DataBar` | **停下来报告**，不要覆盖；Lead 决定是复用还是改名 |
| `--success` / `--info` / `--amber` 前端代码里已经在用但 `:root` 没定义 | 报告出来（这是既有 bug），B0 顺手补上定义即可，但要在回报里写明 |
| `@apply` 报「class 不存在」 | 说明 token 没生效，先确认 `:root` 里的变量名，再检查 `tailwind.config.js` 的 `theme.extend.colors` 是否已映射 |
| Drawer 的 Esc 在测试里不触发 | 检查是否正确用了 `Dialog.Root` 的 `onOpenChange`，不要自己监听 keydown |
