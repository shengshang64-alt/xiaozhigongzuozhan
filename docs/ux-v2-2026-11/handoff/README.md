## 最快路径（推荐）

1. 打开 `PASTE-直接粘贴.md`
2. 复制 `===` 之后的全部内容
3. 把第 1 段的 `本批批次：B0` 改成你要做的批次
4. 整段粘贴给 ZCode
5. 它会先读文件、回报四门基线 + 计划，**等你确认后才写代码**
6. 做完你自己跑一遍 `node docs\ux-v2-2026-11\acceptance\verify-ux-v2.mjs --batch B0`

**为什么 PASTE 文件里要它自己去读那几份文件**：因为 10 份任务书加起来 11 万字，一次性全塞进上下文会挤掉真正重要的东西（现有代码）。PASTE 只传"怎么读、怎么改、怎么验"的**规程**，具体某批的写域与改造清单，让它自己去读对应的那一份。

## 这批任务书里已经钉死的三件事

### 1. 每个批次的写域白名单

任务书第二节明确列出「✅ 允许改」与「❌ 禁止改」。
模型改白名单外的文件 = 本批作废，验收脚本会查（`[红线]`、`[写域越界]`）。

### 2. 每个批次的完成标准

每份任务书第九节左右有「完成标准」逐条清单，验收时直接对照。

### 3. 每条改造都写清了「原状态 → 目标」

不是"优化一下客户管理"，是：

> **"缺 N 项"角标可点** | 原状态：黄色角标，点击无反应 | 目标：点击弹层列出缺失字段，每项带「去补全」直达

这样模型没有"自由发挥"的空间。

## 验收脚本能查什么

```powershell
node docs\ux-v2-2026-11\acceptance\verify-ux-v2.mjs --batch B2
```

| 检查项 | 说明 |
|---|---|
| 路由注册 | manifest 69 屏 vs `routeRegistry` 实际注册 |
| 旧路径兼容 | 17 条模块根路径是否仍注册（防外链失效） |
| 行数纪律 | 本轮改动的 `*Page.tsx` ≤400 行、`use*.ts` ≤800 行 |
| 硬编码色值 | `#RRGGBB` / `rgb()`（跳过 SVG 生成器与导出模板） |
| 一屏一主 CTA | `variant="default"` 数量（弹窗内扣除） |
| 禁用按钮带原因 | `disabled` 附近 260 字符内有无解释文案 |
| 三态齐全 | 每模块是否有 Loading / Empty / Error |
| 红线文件 | `.qoder/`、`eslint-budget.json`、`pb_data`、`.env` |

**设计原则**：默认只查本轮改动。拿存量的债（`BidFigure.tsx` 的 SVG 色值、`CompetitorsPage.tsx` 1078 行）去卡本批，只会逼模型"顺手改"别的地方 —— 那正是要防的。要查存量加 `--all`。

## 三条最容易踩的坑（先提醒）

1. **B1 的 `import()` 不能提前指向不存在的文件** —— 只声明模块根屏，逐批补（任务书里叫"方案 A"）
2. **`vite build` 必须带 `$env:CODEBUDDY_SAFE_DELETE_BULK_THRESHOLD=100000`** —— 否则 `dist/` 清空时触发 safe-delete 拦截
3. **`docx` / `xlsx` / `pptxgenjs` 必须保持动态 `import()`** —— 项目有 `onDemandHeavyLibs.test.ts` 守卫，静态引入会红
