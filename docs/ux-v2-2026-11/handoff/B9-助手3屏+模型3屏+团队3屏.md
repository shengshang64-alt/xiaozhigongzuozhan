## 三、小智助手 3 屏

### 3.1 会话（`/assistant`）—— 核心屏

| # | 改造 | 原状态 | 目标 |
|---|---|---|---|
| 1 | **会话自动命名** | 全是「快捷会话 14 天前」，无法找回历史 | 语义标题（"蚌埠标书还差哪几章"）+ 最后一条消息预览 |
| 2 | **上下文感知** | 3 个固定快捷问题 | 随当前页面变化（在标书页问"这份标书还差几章"） |
| 3 | **能力卡片区** | 无 | 4 张卡（查数据/写文档/做检查/跑流程），各带 2 个示例问句 |
| 4 | **能力边界** | 底部一行小字 | 右栏常驻卡：「我能读…能生成…但不能替你提交审批」 |
| 5 | **记忆/技能入口红点** | 藏顶部 Tab，多数人没点过 | 入口带红点引导 |

**布局**：左 260 会话列表 / 中 1fr 对话区 / 右 320（能力边界 + 当前上下文 + 最近引用）

**上下文感知实现**：
```ts
// 从 modulePathOf(pathname) 拿当前模块，映射到一组示例问句

  "/bid-workspace": ["这份标书还差哪几章？", "还有哪些废标风险没处理？"],
  "/customer-management": ["哪些客户超 90 天没跟进？", "厦门市中医院最近一次跟进是什么时候？"],

  // …
}
```

⚠️ **上下文感知是本批唯一新增的"功能"**，其余都是布局重组。如果实现成本过高（需要读全局路由状态），**降级为「按模块分组显示快捷问题」并在回报里说明**。
