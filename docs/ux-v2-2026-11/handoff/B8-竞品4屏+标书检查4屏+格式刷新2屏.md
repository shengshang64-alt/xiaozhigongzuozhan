## 三、竞品分析 4 屏

### 3.1 核心决策：默认 Tab 改为「应标视角」

**原状态**：默认 Tab 是「市场总览」—— 四张亿级大卡 + 五年中标金额排行，回答的是**行业研究问题**。

**售前真正的问题是**：「这标的对手可能是谁？他们大概报多少？我们该怎么打？」

**改造**：默认进 `/competitors` 就是「应标视角」，「市场总览」降级为 `/competitors/market`。

### 3.2 应标视角（`/competitors`）

| 区块 | 内容 |
|---|---|
| 查询区 | 输入医院/项目名 + 时间范围 + 项目类型 + 「分析」主 CTA |
| 结果 1 | **该院历史中标厂商 Top3**（表格：厂商/中标次数/中标总金额/最近中标/常用品牌） |
| 结果 2 | **价格区间**（chart-bars 或 vbars：近 5 次同类中标价，标出我方报价位置） |
| 结果 3 | **常用参数倾向**（3 条：倾向国产 / 指定品牌数据库 / 要求本地化部署） |
| 右侧 | **应标建议 3 条**（"该院近 3 次均为卫宁中标，建议差异化报价"等 actionable） |

一屏内 + 底部「查看完整厂商档案 →」。

### 3.3 市场总览（`/competitors/market`）

4 张市场规模卡 + 五年中标金额排行（chart-bars 6 条）+ 年度趋势（vbars）+ 数据口径说明（**默认折叠**）。

### 3.4 能力对标（`/competitors/benchmark`）

12 维矩阵（HIS/EMR/LIS/PACS/集成平台/数据中台/DRG/互联网医院/AI辅助/信创适配/实施交付/售后服务）
列：我方 / 卫宁 / 东软 / 行业均值
单元格：强/中/弱/无 + 分值

右侧：差异说明 3 条 + 「导出对标表（用于标书技术分）」主 CTA

现有：`competitorScores.ts` / `competitorsCore.ts`。**复用。**

### 3.5 厂商档案（`/competitors/profile`）

顶部：厂商名 + 徽标（上市公司/成立年份/总部）+ 关注/导出
内容：中标记录表 8 行 + 常用参数 + 报价区间 chart-bars + 竞争话术 3 条
底部：「历史交手 5 次，我方胜 2 负 3」+ 胜负原因

现有：`competitorEvidence.ts`(21KB) / `marketIntel.ts`(25KB)。**复用。**

## 四、标书检查 4 屏

### 4.1 核心改造：工具页回归极简

**原状态**：两个等宽大卡（上传文件 / 选择项目）并列 + 灰色禁用「开始检查」不说原因 + 下方 60% 空白。

### 4.2 新建检查（`/bid-check`）

| # | 改造 |
|---|---|
| 1 | **单一居中上传区**：一个大虚线框，内含两个入口（点击选择文件 / 从标书项目选择） |
| 2 | **模式单选卡**（带说明）：普通模式（只读正文，约 40s）/ 暗标严格模式（含元数据，约 90s） |
| 3 | **禁用按钮带原因**：「开始检查」旁写「选好文件与模式后可用」 |
| 4 | **最近检查报告 3 条**（替代原 60% 空白） |

### 4.3 检查中（`/bid-check/running`）

大进度卡：环形/条形 68% + 「正在执行：暗标规则包 3/5 · 格式规则包 2/6」+ 已用时 + **取消按钮**
规则包清单 5 行（包名/状态/已发现问题数/耗时）
右侧实时冒出的问题 3 条
底部：「检查会在本地完成，不上传文件内容」

⚠️ **必须能取消**。现有 `runCheck.ts` 是否支持取消需先查；不支持则本批不做取消，但要报告。

### 4.4 检查报告（`/bid-check/report`）

顶部：文件信息条 + 结果徽标「23 个问题（阻断 2 / 警告 8 / 提示 13）」
左 1fr：问题清单表（级别 / 规则名 / 问题描述 / 原文位置 / 操作）
右 380：按规则包分布（chart-bars）+ 三种导出（批注 docx / Excel / HTML）
主 CTA：「导出带批注的 docx」

**规则名必须来自现有真源**（`src/pages/BidCheck/rules/*.ts`），不许自造。
例：`L5-A1 公司名称泄露` / `L1-1 正文字体不一致` / `L2-R1 ★条款正文应答核对`。

### 4.5 历史报告（`/bid-check/history`）

表格：文件 / 模式 / 问题数 / 检查时间 / 耗时 / 操作（打开 / 对比 / 删除）
顶部「对比两次检查」示意卡
右侧「检查统计」：近 30 天 24 次 / 平均 18.4 问题 / 阻断类下降 62%

## 五、格式刷新 2 屏

### 5.1 核心改造：安全长文改为确认弹窗

**原状态**：右栏第 4 步有约 200 字密集小字说明（保存逻辑与覆盖规则），没人会读。

**改造**：改成一句话 `alert--warning` + 折叠「查看覆盖规则」，真正的长说明挪到「点套用时」的确认弹窗里。

### 5.2 ① 上传与模板（`/format-tool`）

左：上传区 + 已上传文档（"XX医院标书_终版.docx 4.2MB / 46 页 / 字体混用 7 处"）
中：3 张模板卡（公司标准 / 智业投标 / 政采通用）
右：刷新范围勾选（正文样式/标题编号/表格/图注/页眉页脚/页边距）

**安全说明压缩**：一句话 `alert--warning` + 「查看覆盖规则 ▸」折叠
主 CTA：「下一步：预览对比」

### 5.3 ② 预览套用（`/format-tool/preview`）

左右对比：原文档 vs 刷新后（两个纸张模拟块，高亮差异处 + 角标 ①②③）
上方差异摘要：「共 128 处变更：字号 62 / 行距 31 / 编号 22 / 表格 13」
右侧 340：微调配置（**默认收起**）+ 套用与导出区

**按钮带序号**：
- ③ 一键应用到文档（主）
- ④ 导出刷新后文档

**「一键应用」必须二次确认**：弹窗内 `.danger-box`「将覆盖原文件，原文件会自动备份为 .bak」

现有：`formatSpec.ts`(25KB) / `refreshDocx.ts`(44KB) / `formatDiff.ts`。**全部复用，不改。**
