记忆是怎么被用的

每次提问，助手会先挑最多 5 条相关记忆放进上下文，再回答。所以「报价折扣」这种偏好不需要你每次重复。
1你提问 → 按关键词 + 类型召回记忆
2命中的记忆作为「前提」参与生成
3回答末尾标注「引用：记忆 2 条」
4已失效记忆不再参与召回，但保留可查
