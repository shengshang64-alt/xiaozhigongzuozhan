弹窗 / 抽屉 / 危险确认

切换到 glm-5.3-flash 作为默认模型？
将把全站 AI 生成切换到该模型，原默认 deepseek-v4.1-flash 退为备用。影响范围：方案生成、标书正文、情报摘要。
停用后该成员将被立即踢出登录会话，历史操作记录保留。可在 30 天内重新启用。
危险操作三件套：红色描边 + 二次确认 + 后果一句话。表单类用居中弹窗（≤560px），详情/预览类用右侧抽屉（≤560px）。

如何评审这套原型

① 逐模块看拆屏是否合理
每个模块顶部有屏内 Tab，描述栏写着"这一屏解决什么问题、原页面为什么放不下"。先判断拆分粒度，再看细节。
② 看关键三屏的密度
标书④正文编写 / 情报审阅 / 客户详情是全站信息最密的三屏，若这三屏在一屏半内可完成主要动作，其余页面不会再超。
③ 对照原页面截图
原页面截图见 docs/ux-review-2026-11/shots/。本原型屏内 note 条与改造账逐条对应。
