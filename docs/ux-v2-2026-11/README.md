# 小智工作站 · 全量界面重构（静态原型）交付说明

> 版本 v2.0 · 2026-11-08
> 需求：从产品经理 / UI 设计师 / 完美主义三个视角，对**全部功能与界面**做分析与优化；解决"功能全堆在一起"；**只做静态界面**；参考大厂设计规范（按钮 / 下拉 / 窗口布局等多维度）。

---

## 一、一句话结论

**线上 17 个路由里，有 5 个页面属于"堆叠型"——单页 9,000+ DOM、800+ 按钮、最长 12,513px（15 屏）。**
本次重构按「**一类决策一屏**」把 17 个页面拆成 **69 屏**，最长页面压到约 1,600px，并把按钮层级、下拉样式、筛选区、表格、弹窗、空态、长任务反馈统一到一套设计令牌上。

交付物是**可直接逐屏评审的纯静态原型**（无后端、无构建、双击即开）。

## 五、三段式改造逻辑（这是评审时最该问的）

### 1. 产品视角：这个功能该不该单独存在？

| 动作 | 具体项 |
|---|---|
| **减** | `/ai-hot` 从导航移除（仅 1 条内容），并入情报中心「行业前沿」 |
| **减** | 首页砍掉 9 个区块（商机分布图、胜负复盘卡、最新动态、情报摘要…） |
| **减** | 方案工作室的教学信息（类型说明、12 个系统标签、模板下载条）折叠 |
| **减** | 模型配置的常驻红色警告折叠为灰卡（这是已知环境限制，不是错误） |
| **升** | 知识原子从"审核页里的一个 Tab"升为一等公民（可复用事实单元） |
| **升** | 竞品分析的默认 Tab 从「市场总览」改为「应标视角」 |
| **升** | 「今日 · 工作台」独立成导航第一组（每天第一站） |

### 2. UI 视角：一屏怎么排？

**4 种骨架取代线上 5+ 种**：仪表盘型 / 主从型 / 向导型 / 工具型。每种骨架的页头、工具栏、内容、翻页位置一致，用户换页不再重新适应。

**每个控件只有一种正确用法**：
- 按钮 4 级（主/次/文字/危险），一屏 1 个主 CTA
- 下拉全站自绘（可分组、带计数、带说明），禁止原生 select 做主筛选
- 筛选常驻 ≤ 4 个，其余进抽屉且显示生效数，禁止两级筛选并存
- 表格吸顶表头、行尾 ≤ 2 个图标 + ⋯ 菜单、> 12 行必分页
- 弹窗 ≤ 560px（表单居中 / 详情抽屉 / 危险专用样式）

### 3. 完美主义视角：每个边界都钉死

- 间距只用 4/8/12/14/16/24/32（线上现在 8/12/16/20/24 混用）
- 字号只用 6 档（线上四档字号的对比度太接近，眼睛找不到落点）
- 语义色只有 5 档且都与"用户下一步做什么"绑定（线上有 4 种红并存）
- 18 项验收清单，带可执行的自检命令
- **禁止行内色值**：所有颜色必须来自 token

## 六、三个具体例子（证明"不是重新排版，是重新判断"）

### 例 1：客户管理的一个角标

原页面每个客户卡带「缺 3 项」黄色角标——**但点击没反应**。用户知道"缺"，不知道缺什么、去哪补。

改造后：角标可点，弹层列出具体缺失字段，每项带「去补全」直达表单；同时列表页顶部数据条直接写「41 家档案不完整」。

**这不只是 UI 改动，是把一个死掉的最后一公里接上了。**

### 例 2：资质台账的 5 张统计卡

原页面 5 张卡同权重：已过期 1 / 30 天内 3 / 90 天内 0 / **未登记有效期 25** / 总数 34。

那个「未登记 25」是全站最行动导向的数字（25 张证书连有效期都没登记！），却和其他数字长得一模一样。

改造后：按危险度着色排序，未登记升为 amber 警报级并写「⚠ 25 张未登记，点击批量补录」，同时新增一个「批量登记」屏承接这个动作。

**这不只是配色改动，是把风险分级做进了扫描路径。**

### 例 3：标书工作台的项目卡

原卡片只有「已开标 / 距开标 25 天」和「0/0 章成稿」——用户必须点进去七步流水线才知道这个项目卡在哪一步。「0/0 章」更是失败表达（分母 0 说明大纲还没生成，用户读不出这层）。

改造后：卡片带七步微缩进度条（绿=已完成 / 蓝=当前 / 灰=未开始），旁边直接写「④ 正文编写 · 3 处废标风险」。

**这不只是加了个组件，是把"项目在哪"这个最常问的问题移到了列表页回答。**

## 七、没做什么（明确边界）

1. **不做响应式移动端专项**：原型按 1280–1920 桌面设计，< 1100px 只保证侧栏折叠 + 单栏可读。售前编制标书是桌面行为。
2. **不改后端数据契约**：字段与线上 `bidTypes.ts` / `customerTypes.ts` 对齐，不发明新字段。
3. **不引入新组件库**：继续 Radix + Tailwind，`design.css` 的 class 可映射为 Tailwind 组合类（映射表见规范书 §6.3）。
4. **不做视觉大换血**：保留医疗青蓝 `#0E7C99` 与深青侧栏，只做层级、密度、语义色的修正。
5. **不删除任何现有路由**：`/ai-hot` 从导航移除但路由保留，防外链失效。
6. **静态原型不含真实交互逻辑**：弹窗、下拉、折叠、选中、toast 可用（`shell.js` 已接管），但不连后端、不写业务状态。

## 八、如果只改一件事

**把「一类决策一屏」落实下去。**

12,513px 和 918 个按钮不是"页面长"，是"一屏塞了六个功能"。视觉细节都可以后补，但**继续往堆满的页面上加功能，代价是指数级的**——每加一个功能，用户找到已有功能的成本都会上升。
