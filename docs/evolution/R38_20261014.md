## 3 · 口径纪律（本轮的硬约束，均有单测钉住）

1. **认不出就不算**：价格分项存在但公式无法机械复算 → `phase:"unrecognized"`，逐条列「哪个评分项、为什么不算」，**一个数字都不出**（不代招标文件猜数）。
2. **相对分必须有参照系**：缺对手报价 → 只说原因，不给「假设基准价」。
3. **对手报价只能手输**：竞对情报 `competitor_evidence` 存的是**历史中标金额**，不等于本次投标报价，冒用会把评标基准价算歪——面板把这句话直接写在输入框下方，并加哨兵禁止引入 `competitorEvidence`。
4. **单位歧义不静默换算**：手输「1200」按 1200 元如实计算，同时挂 `unitHint`（不足限价 1% 时点破「疑似把万元按元填写」）——与 B8「不静默钳位」同处置口径。
5. **建议价不得踩废标线**：`fullScoreTargetPrice` 的临界价若落进无效标区间（真实语料：低于限价 45% / 超限价），保留得分但红字标注「不能为拿价格分把标做废」。
6. **取数走单源**：评分项走 `scoringItemsFromReport`、事实行走 `effectiveGlobalFactsLines`、天花板走 `priceCeilingFromFacts`（硬限价优先于预算）、我方报价走 `pickLatestQuoteTotals`——不新造任何第二套取数路径。
