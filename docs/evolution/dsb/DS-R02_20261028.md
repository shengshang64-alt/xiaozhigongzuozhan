## 过程中修掉的两个真实误报（这是本轮的技术价值）

### 误报① 通用表述被当成医院名

朴素正则 `/([\u4e00-\u9fa5]{2,12}医院)/` 抽出来的脏数据：

```
「包含医院」「互联网医院」「安徽省评级过级医院」「三甲综合医院」「省互联互通四级甲等及以上医院」
```

这类值进结构化字段后，生成标书会写出「服务过包含医院」这种废句。

**修法**：黑名单 + 「及以上/以下/等/的」收尾排除。

### 误报② 贪婪吞并前文

```
原文：「服务过蚌埠医学院第一附属医院」
抽出：「服务过蚌埠医学院第一附属医院」  ← 把动词「服务过」吞进机构名
原文：「某医院智慧医院项目」
抽出：「某医院智慧医院」                ← 把后续词吞进机构名
```

**修法**：左边界去掉动词/介词前缀；右边界遇「智慧/信息/项目/建设」等跨词标志则截断。

**修完实测**：样例医院名全部为真实机构（蚌埠医学院第一附属医院 / 太和县人民医院 / 厦门大学附属第一医院），
抽取率 90.3% → 89.7%（只损失 0.6% 的脏数据，符合「宁可抽不到也不抽错」的真实性红线）。
