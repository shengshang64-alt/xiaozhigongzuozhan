## 一句话结论

**旧版会把语义无关的条目硬配上，比留空更糟。** 实测「体检信息管理系统」被配成「病理管理系统」、
「移动护理信息系统」被配成「超声管理系统」——用户不逐条核对根本发现不了。
本轮重写匹配核心：先剥通用后缀取**语义核心词**再比对，分「自动填 / 候选 / 留空」三档。

12 条真实招标措辞实测：**10 条正确命中、2 条正确留空、0 条错配**（旧版 4 条错配）。

## 问题 → 根因 → 修法 → 验证

### 问题：匹配算法对中文语义无效

**实测数据**（用用户提供的真实公司文件 `01-2022年【智慧医院信息化建设- ONE-LINK】2025第4.1版.xlsx` 建库，549 行）：

| 医院清单写法 | 旧版配成 | 编辑距离 | 性质 |
|---|---|---|---|
| 体检信息管理系统 | 病理管理系统 | **0.750** | ❌ 完全错 |
| 移动护理信息系统 | 超声管理系统 | 0.625 | ❌ 完全错 |
| 医保结算清单管理系统 | 医保对账管理系统 | 0.600 | ❌ 错 |
| 互联互通测评支持服务 | 互联互通自评估管理 | 0.800 | ⚠️ 接近但不同 |
| **电子病历系统（EMR）** | （未命中） | **0.545** | ❌ **正确答案反而被拒** |

### 根因（三层，逐层实测确认）

**① 编辑距离对中文短名不成立。** 「体检信息管理系统」与「病理信息管理系统」共享 6 个字
（信息管理系统），编辑距离 0.75 轻松过阈值 0.6，但语义核心「体检」vs「病理」毫无关系。

**② 「包含即 0.9」不分方向。** `mappingCore.ts` 旧代码：

```ts
const containment = normCustomer.length >= 3 && (normCustomer.includes(cn) || cn.includes(normCustomer))
if (containment) { bestScore = 0.9; ... }
```

`「移动护理」.includes(「病人管理」)` 与 `「门急诊挂号收费」.includes(「挂号收费」)` 拿到同样的 0.9，
但前者是错配、后者是正确同义。**方向不同，语义完全不同。**

**③ 拿产品线名当匹配字段（张冠李戴）。** 这是本轮新发现、且旧版诊断没看到的一层：

```
查询「移动护理信息系统」
  命中字段 = product_name = "急诊移动护理"     ← 产品线聚合名
  展示出来 = 该产品线下的第一个模块「病人管理」  ← 张冠李戴
```

「急诊移动护理」是一条产品线，底下挂着 病人管理/输液管理/文书管理/输血管理/检查检验管理 等模块。
用产品线名匹配、却展示模块名，用户看到的就是「移动护理 → 病人管理」这种无厘头结果。

### 修法

**① 剥通用后缀取语义核心词**（新增 `semanticCore`）

```ts
const GENERIC_SUFFIXES = ["信息管理系统","信息管理平台","管理信息系统","信息平台",
  "管理系统","信息系统","管理平台","服务平台","支持服务","管理软件","子系统",
  "系统","平台","模块","软件","应用"]   // 长的优先剥

semanticCore("体检信息管理系统")   // → "体检"
semanticCore("移动护理信息系统")   // → "移动护理"
semanticCore("电子病历系统（EMR）") // → "电子病历"（括号缩写先摘掉）
```

**② 五条规则分档打分**（`scoreProductMatch`）

| 规则 | 条件 | 分数 | 档位 |
|---|---|---|---|
| exact | 全名完全一致 | 1.00 | **自动填** |
| abbrev | 英文缩写命中（LIS/PACS/DRG） | 0.96 | **自动填** |
| core-exact | 语义核心词完全相等 | 0.97 | **自动填** |
| core-contain | 客户核心词落在公司核心词里 **且覆盖率 ≥0.5** | 0.95~0.99 | **自动填** |
| core-contain | 反向包含 / 覆盖率不足 | 0.80~0.95 | 候选（不自动落） |
| core-sim | 核心词编辑距离 ≥0.75 **且长度差 ≤2** | ≤0.85 | 候选 |

**③ 产品线名不再当匹配字段。** 只有模块名与标准名都为空时才回落 `product_name`。

**④ 三档阈值**

```ts
export const AUTO_FILL_MIN = 0.95   // 只有 ≥0.95 才自动填
export const SUGGEST_MIN  = 0.75    // 0.75~0.95 给候选，交用户点选
                                    // 低于 0.75 留空
```
