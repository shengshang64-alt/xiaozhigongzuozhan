## 一、先定架构图类型（选错类型，画得再漂亮也白搭）

| 类型 | 何时用 | 结构 |
|---|---|---|
| **分层架构图** | 讲系统整体组成 | 5 层砖墙：渠道→接入→业务→能力→数据 |
| **DDD 四层图** | 讲某个核心系统的内部结构 | 接口→应用→领域→基础设施（+外部域+横切） |
| **业务→技术映射图** | 向非技术领导解释"技术从哪来" | 三栏递进：业务能力→映射→技术服务 |
| **用例→非功能推导图** | 解释"为什么需要这个中间件" | 三列对照 + 落地简图 |
| **数据流/集成图** | 讲系统间接口和数据流向 | 系统节点 + 有向连线 + 协议标注 |

## 二、分层架构图的硬规则

```
┌──────────┬─────────────────────────────────────┐
│ 渠道层    │ 互联网医院 · 移动App · 自助机 · 大屏    │
├──────────┼─────────────────────────────────────┤
│ 接入层    │ 网关 · 统一认证 · 单点登录 · 安全防护   │  ← 必须有
├──────────┼─────────────────────────────────────┤
│ 业务层    │ 按业务域分片：门诊/住院/医技/药事/管理  │  ← 核心
├──────────┼─────────────────────────────────────┤
│ 能力层    │ 集成平台 · 数据中心 · 主索引 · 数据治理 │
├──────────┼─────────────────────────────────────┤
│ 数据层    │ 业务库 · 临床数据仓库 · 数据中台       │  ← 必须有
└──────────┴─────────────────────────────────────┘
   横切：信息安全 · 运维管理 · 标准规范（右侧竖排）
```

**必守 8 条**：
1. 层序自下而上逐层支撑，不跳层
2. 层名 ≤6 字、职责单一（禁"其他""支撑"这类空泛名）
3. 每层 3-6 个模块，超出就再分层
4. 模块名用行业真实系统名（HIS/EMR/LIS/PACS/CDSS/集成平台/主索引），**禁编造**
5. 业务层必须体现**业务域分片**，不能把所有系统平铺
6. **必须画非功能能力**：网关/鉴权/监控/日志/配置/数据治理——"业务图不会说但架构必须有"
7. 层数 4-6 层，超 7 层说明没收敛
8. 横切关注点（安全/运维/标准）单列在右侧，不打断主链路

**自检**：
- 同层模块是否同粒度？
- 调用关系是否单向（上层调下层）？
- 有没有孤儿模块无处挂靠？
- 图上能不能看出并发/一致性/可用性/合规？

## 三、视觉语法（全项目统一）

| 元素 | 含义 |
|---|---|
| 实线框 | 有边界的组件 |
| **实线箭头** | 同步调用 / 强依赖 |
| **虚线箭头** | 异步消息 / 弱依赖 |
| 虚线无箭头 | 配置 / 编译依赖 |
| 虚线大框 | 限界上下文 / 自治边界 |

**颜色语义**：蓝=业务、绿=中间件/数据、橙=边界/渠道、灰=支撑、红=风险/约束

**黄金法则**：**连线交叉超过 5 处 → 先查分层或分域是否混乱，别急着调线。**

## 四、售前 PPT 版式规范

### 视觉基调
- 主色：**深藏青**（#1B3A5C 系）+ 白底
- 辅色：墨绿 / 赭石 / 紫灰 / 中灰（每页 ≤4 色，一色一义）
- 字体：标题黑体 Bold，正文常规黑体
- 风格：扁平 + 细线图标 + 大留白，**不用阴影渐变**

### 五类高频版式
| 版式 | 结构 | 场景 |
|---|---|---|
| **封面页** | 左侧超大标题+副标题+年份，右侧实景建筑图叠加数据元素，底部 4 个图标分类卡 | 开场 |
| **四列对照表** | 表头带色块（依据/要求/动作/边界），每格图标+文字 | 政策依据、职责分工 |
| **指标进度表** | 行=指标，列=基线/年度目标，格内带横向进度条 | KPI、目标体系 |
| **①-⑥ 流程卡** | 6 个等宽卡片横排，卡内编号+标题+小图 | 方法论、六步法 |
| **三栏并列卡** | 编号+标题+图标矩阵+实景图+关键指标条 | 资源协同、场景拆解 |

### 版式细节
- 编号块：深色圆角方块 + 白色"01" + 竖线 + 标题
- 进度条：浅灰满宽底 + 深色实心条，数值写在格子里不在条上
- 指标表：表头深底白字、隔行浅灰、数字右对齐
- 图标：统一线性风格（Lucide/Feather），尺寸一致
- 实景图：圆角裁切（病房/手术室/CT/门诊大厅），增强行业代入感

## 五、本项目实现路径

现有能力（`src/pages/PptQuote/`）：
- `figures` 图型：`architecture` / `flow` / `demo` / `mermaid` / `image`
- 渲染器：`src/components/bid-workspace/BidFigure.tsx` → `buildFigureSvg()`
- 导出：`deckExports.ts` → `figureSpecToDataUrl()`

**当前架构图渲染是「单色横条」**，若需达到范文水准，需升级 `architectureSvg()`：
1. 支持 `layers[].color` 分层配色
2. 左侧色块层标签（而非文字）
3. 层间向下箭头 + 协议标注
4. 支持 `crossCutting[]` 右侧竖排横切条
5. 业务层支持二级分组（域 → 模块）

**提示词已注入** `ARCH_RULES`（`pptQuoteTypes.ts`），AI 生成 figures 时会遵守上述铁律。
