## 一、禁用词与推荐替换词

用户可见文案（按钮、标题、菜单、提示、弹框、空态文案）一律不得使用下列词：

| 禁用词 | 推荐替换 | 说明 |
|--------|----------|------|
| 作战 | 导航 / 工作区 / 速览 / 总览 | 「作战地图」→「导航」；「作战室」→「项目速览 / WarRoom」 |
| 制胜 | 完成 / 交付 | 动词位替换 |
| 决胜 | 达成 / 成功 | 动词位替换 |
| 杀手锏 | 关键手段 / 优势项 | — |
| 利器 | 高效工具 | — |
| 赋能 | 支持 / 增强 / 帮助 | 「组装层赋能」→「组装层增强」 |
| 抓手 | 工具 / 方法 / 入口 | — |

统一用词（防同物多名）：

| 统一术语 | 不再混用 |
|----------|----------|
| 标书工作台 | ~~标书工作~~ |
| 情报 | ~~资讯~~（业务场景内） |
| 新建 | 新建 / 添加按场景区分：「新建商机」「添加待办」，同一场景只用一个动词 |

## 三、白名单（功能内容，不属文案违例）

`scripts/check-prohibited-words.js` 的 `ALLOW_FILES` 逐条留档了放行理由，核心结论：

1. **反 AI 套话链路（不能改）**：`bidProseLinter.ts` 的规则词表、`bidTypes.ts` / `pptQuoteTypes.ts` / `solutionTypes.ts` 的提示词禁词表——「赋能 / 抓手」在这里是**被拦截对象**本身，产品功能就是要阻止这些词出现在标书正文里。
2. **PPT 配图判定（不能改）**：`deckVisualPlan.ts` 的抽象词表驱动配图策略，属功能关键词。
3. **事实数据（不能改）**：`marketIntel.ts` 中「AI 赋能临床」是对东软公开战略的转述。
4. **测试夹具（不能改）**：`bidProseLinter.test.ts`、`deckVisualPlan.test.ts`、`intelBodyClean.test.ts` 中的词是行为测试与真实抓取样本的输入。
