## 一、实施内容

### 1.1 写回链路扩展（ChatStream.tsx SkillAdoptRow）

将 ADOPTABLE 集合从 3 项扩展到 6 项预设技能全覆盖：

| 技能 | 采纳动作 | 写回目标 |
|------|---------|---------|
| 写客户跟进邮件 | 选客户→存档 | follow_records POST |
| 生成周报总结 | 下载 Word | docx 引擎 |
| 竞品深度分析 | 选竞品→追加写入 | competitors.threat_notes PATCH |
| 招标文件要点梳理 | 选标书项目→追加 | bid_projects.ref_materials_text PATCH |

| 方案大纲构思 | 复制+跳转方案编辑器 | 剪贴板 |

## 三、设计决策

- **追加不覆盖**：threat_notes/ref_materials_text 采用换行+分隔符追加策略，保留历史内容
- **不新建集合**：全部走既有 PocketBase API（follow_records / competitors / bid_projects）
- **自定义技能不展示采纳**：未知写回目标，避免误操作
- **方案大纲构思暂不自动解析 chapters**：V1 仅 copy+nav（复杂度和错误率太高），后续可迭代

## 四、已知限制

- 方案大纲写回为"复制+跳转"非自动入库（V2 迭代方向）
- 竞品列表 API 需 auth（本地 dev 正常；沙箱需 X-Pb-Auth 头，已由 pb.beforeSend 统一处理）
